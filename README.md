# App-treino

Página web com a ficha de treino de academia de uma pessoa, dividida em três treinos (A, B e C) com exercícios, séries, repetições, descanso e foto de cada exercício.

Demo: https://joaoequer.github.io/App-treino/

## Funcionalidades

- Treino A (peito/ombros/tríceps), B (costas/bíceps) e C (pernas): lista gerada por JavaScript a partir de um objeto `workouts` em `index.html`.
- Cada exercício mostra nome, imagem, séries, repetições e, quando definido, descanso em segundos.
- Os dados ficam fixos no código. Não há registro de treinos, cronômetro nem histórico.

## Tecnologias

HTML, CSS e JavaScript puro.

## Como rodar localmente

Sem build: abra `index.html` no navegador.

## Estrutura

- `index.html` - página e dados dos treinos
- `styles.css` - estilos
- `imagens-dos-exercicios/` - imagens dos exercícios

## Status

Projeto pessoal pequeno. Alguns nomes de imagem no código diferem dos arquivos da pasta, então algumas imagens podem não carregar.
